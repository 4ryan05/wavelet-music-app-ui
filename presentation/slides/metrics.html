Module 5, measuring UX performance as a strategy. These are our targets, not results yet. We would run a small usability test with five participants using the Figma prototype, time the main task, count errors in the sign-in form, and finish each session with the System Usability Scale questionnaire. After launch, day-7 retention tells the business whether people keep coming back.
